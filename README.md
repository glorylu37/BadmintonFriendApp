# BadmintonFriendApp

一个用于羽毛球自我测评、能力标签和约球匹配的微信小程序课程项目。

本仓库用于《AI软件开发环境安装与配置》实验，记录个人软件项目的初始化过程、运行入口、版本管理和后续开发方向。

## 项目目标

球友完成动作自我测评后，系统生成基础能力标签；发布或报名球局时，参与者可参考彼此的标签寻找实力相近的球友，并获得后续训练建议。

当前原型验证三条核心流程：

1. 进入自我测评页面并生成演示标签。
2. 在主页查看个人能力标签。
3. 查看按水平标注的附近约球活动。

姿态测评能力计划参考开源项目 ShuttlePoseReview、badminton_training 等，后续接入视频上传和姿态分析服务。测评结果仅用于训练与匹配参考，不作为医疗或专业运动诊断。

## 技术栈

- 微信小程序原生框架
- 微信开发者工具 `2.01.2510290`
- JavaScript、WXML、WXSS
- 后续计划：微信云开发与 Python 姿态分析服务

## 本地运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 选择本仓库根目录。
4. 使用测试号或自己的小程序 AppID 编译运行。

项目内 `project.config.json` 使用 `touristappid`，仅用于本地学习和演示；发布前必须替换为自己的 AppID。

## 目录结构

```text
BadmintonFriendApp/
├── app.js                 # 小程序入口
├── app.json               # 页面和窗口配置
├── app.wxss               # 全局样式
├── pages/
│   ├── index/             # 首页和能力标签
│   ├── assessment/        # 自我测评演示
│   └── matches/           # 约球活动列表
├── project.config.json    # 微信开发者工具项目配置
└── project.private.config.json # 本地私有配置，不提交
```
